龙头策略 · "大盘站上MA60才做" 的判定时点对比

初始资金 ¥100,000.0 · N=3 · 持3天 · 无止损 · 回测区间 2024-06-03~2026-07-14 · 仅改变【闸口判定时点】, 龙头选股/买入价/持有期完全一致

一、三种时点的问题映射

问题1 开盘前判定 → 变体 open:信号日T开盘前只用T-1收盘, gate[T]=T-1收盘站上MA60[T-1], 完全无前视, 可隔夜定计划。
问题2 14:45选股时判定 → 变体 close1445_proxy(日线无盘中指数, 用T收盘近似)与 close1445_strict(严格无前视: T收盘 vs MA60[T-1])。
问题3 持续2/3天在MA60上方 → 变体 persist2/3_open(开盘前版, 用T-1往前数)与 persist2/3_close(14:45版, 用T往前数)。

逻辑注意点(请检查): ① 龙头选股始终用信号日T自身数据(14:44选股、收盘买入); 闸口只决定"本周期是否动手", 不改变买哪只。
② open版用T-1状态定闸口, 但若T当日大跌收盘破MA60, 仍会在T收盘买入——它放行的是"昨天还好、今天可能变坏"的日子。
③ close1445_proxy用T收盘定闸口, 等价于"收盘确认收盘买", 比open版多一丝前视(因为14:44时尚无T收盘)。
④ 日线数据没有盘中指数, 真正的"14:45实时指数 vs MA60[T-1]"无法精确回测, proxy版是标准近似; strict版把MA60换成T-1已知值, 二者几乎相等(MA60变化极小)。
⑤ persist版更严格(动手更少、等待更多), 每个动手日都处于更深的上升趋势中, 但交易笔数更少、可能少赚。

三、最优情况描述(供逻辑核对)

收益最优: 开盘前 (T-1收盘站上MA60[T-1])

判定逻辑:每个信号日(每3个交易日)按"该变体定义的信息时点"检查大盘(等权全A净值代理)是否站上60日均线:

  • 满足 → 正常买入当日热门行业龙头第1/2/3名, 收盘成交, 持有至第3个交易日收盘"到期"离场;
  • 不满足 → 本信号周期不新建仓、现金等待(记录"空仓等待"); 已持有的老仓位仍自然到期离场, 不中途砍;
  • 下一个信号日(再+3交易日)重新判定, 满足则再动手。

该最优变体结果:期末净值 ¥321,625 / 总收益 +221.62% / 胜率 50.6% / 夏普 2.397 / 最大回撤 19.49% / 共 174 笔 / 空仓等待占 31.0%( 26/84 个信号周期)。

对比始终在场: 收益少约 -5 点, 但回撤从 30.7% 降到 19.5%, 且有近 31.0% 时间干脆空仓——机会不对就等。请对照上表确认该变体的"判定时点"描述是否符合你的直觉。

若更看重胜率而非总收益, 胜率最高变体为 开盘前 (T-1收盘站上MA60[T-1]) (收益 +221.62% / 胜率 50.6%)。
