4. 逻辑核对要点(请你检查)

  • 可比性：两策略均用同一 DB、同一测试窗口、10万本金、0.008 双边滑点、事件驱动满仓模型。生产动量额外并列持3/持5两版，C 为其最优单版。
  • C 的收益来源：= 高胜率(75.9%) × 少数肥尾大赢家(4笔≥+10%) − 极少的极端亏损(7笔)，本质是"低频、精选、让利润奔跑"。若未来热门题材熄火，机会数会锐减(强市20笔 vs 弱市13笔)。
  • C 的脆弱点：①单笔最差 -10.37%(整仓无硬止损，仅靠隔天高开与到期)；②依赖题材行情，机会数不稳定；③14:45 尾盘偷袭板的真实成交/冲击成本可能高于回测滑点假设。
  • 生产动量为何落后：当前 DB 下自适应退出"止盈太早+止损太频"，导致 62 笔小亏、0 笔大赢，胜率不足五成，被摩擦成本蚕食。
  • 不是"C 永远赢"：results.json 旧快照里生产动量曾 +33%，说明其表现强依赖数据窗口；C 的优势在当前窗口显著，但同样需要题材活跃度支撑。建议把 C 作为"题材活跃期的进攻卫星仓"，而非全天候替代生产核心策略。
