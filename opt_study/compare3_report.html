核心结论

① 胜率冠军 = 策略 A(多因子框架+热门闸口+择时)
胜率 57.5%(N=2, 持有5天), 8窗口均值胜率全部 54–57%, 远超龙头法的 38–51%。 回撤仅 13.7%(全配置最低), 收益为正(+6.8%~+14.0%)。这是"想赢更多次、且风险可控"的最优解。
② 收益冠军 = 策略 C(龙头无择时, 持有3天, N=3)
收益 +244%、夏普 2.11、胜率 51.3%、回撤 22.4%。 但代价是 252 笔高频交易 且为无止损买&持有(N=1 时回撤高达 56%)。属于"高收益、胜率仅五成、需强风控"的打法。
③ 策略 B(龙头+择时)被双向压制 — 不推荐
加 MA20 择时闸口后, 龙头的胜率没超过 A(仍 38–51%), 收益却被砍到只有 C 的一半左右 (C N=3 h=3 收益 +244% → B 同配置 +128%)。 原因: 龙头是短动量, 日级 MA20 太粗, 闸口频繁误杀好买点(震仓)。 择时闸口对"持5天的框架(A)"有用, 对"持3天的龙头"反而添乱。

胜率对比

A 全配置稳居 54–57% 一线(红), 龙头法(B/C)多在 38–51% 波动。可见"框架严选+热门闸口+择时"对胜率的提升最扎实。

收益对比

龙头法(C, 蓝)在 3天持有下收益极高(尤其 N=3 的 +244%), 但这是无止损、高换手的结果; A(红)收益稳健为正。B(橙)被择时闸口拖累, 收益明显低于 C。

逐策略解读与落地建议

A · 多因子框架 + 热门闸口 + 择时
= 原框架全口径(≥2亿成交额 + 套牢盘≤0.10 + sharpe>1.0 + 自适应止盈止损), 选股前加"仅限热门行业"闸口(复用你的择时开关同位置), 再叠加市场破MA20空仓。
• N=1: 收益 +14.0% / 胜率 55.4% / 回撤 13.7%
• N=2: 收益 +9.3% / 胜率 57.5%(全场最高) / 回撤 13.7%
建议: 想"少操心、高胜率、低回撤"就选它; N=2 胜率最高, N=1 收益最高。
C · 热门行业龙头(无择时)
= 14:45 选热门行业(资金净流入 top-8)内当日涨幅前 N 的龙头, 买&持有。
• N=3 / 持有3天: 收益 +244% / 胜率 51.3% / 夏普 2.11 / 回撤 22.4% / 252笔。
建议: 追求极致收益可选, 但务必另加止损/仓位管理(无退出规则时 N=1 回撤达 56%); 且高频换手对执行/滑点敏感, 实盘小资金验证。
B · 龙头 + 择时(破MA20空仓) — 不建议
理论上"龙头强势 + 大盘保护"最完美, 实测却两头不靠: 择时闸口对短动量龙头是负贡献(误杀+震仓), 既没拿到 A 的胜率, 也没拿到 C 的收益。若坚持龙头路线, 直接用 C 并自带止损即可, 不必叠 MA20 闸口。

口径与注意

  • 热门行业: 按板块当日主力资金净流入排名 top-8(逐股 成交额×(2×收盘−最高−最低)/(最高−最低) 汇总)。
  • 退出机制差异(如实标注): A 用原框架 ExitRuleEngine(自适应止盈止损); B/C 用简单买&持有(无原框架的流动性/套牢盘过滤), 故 B/C 的"高收益"含未风控的尾部风险。
  • 14:45 价以当日收盘近似(库内无14:45缓存); 实盘以真实14:45价下单, 结果可能略异。
