# 2026-07-16 四种"可成交龙头"场景 × 基准动量 对比回测

## 任务
用户要求回测4种"非追涨停"的可实盘龙头场景, 与基准动量策略对比(延续上一轮"涨停买不进"结论, 这4种场景本质都买"没封板的强势股/分歧日", 规避买不进陷阱):
- A 首裂/炸板低吸(全天观察): 当日曾触涨停但炸开未封死仍收涨, 或早盘低开≥1%震荡企稳; 近3日曾涨停/近5日涨>15%(强势股)。
- B 回踩均线(二波): 收盘回踩5日线(±3.5%)或10日线(±5%), 缩量(量<5日均量×0.85), 且近期曾涨停。
- C 尾盘偷袭板/潜伏板: 收盘涨幅>5%且收在最高附近(尾盘拉起), 开盘不在涨停附近(非早盘板), 最高曾摸涨停未封死(试探), 博弈隔天溢价。
- D 断板反包: 前1~2日曾涨停(龙头), 今日断板(未涨停)且回调-6%~+3%, 缩量, 尾盘企稳(收盘在当日上半区)。
- 基准动量(同框架): 热门行业内按5日动量(mom5)降序选Top-N。

## 框架
- harness_scenarios.py: 从 data_cache 预建 per-code 量价/均线(ma5/ma10)/量能(vma5)/涨停序列(lu, limit_price); 4场景+动量共5个选股函数; 统一账户级回测(买入=收盘×(1+SLIP), 涨停封板防御跳过, 持2/3天到期, 可选MA60开门闸口); 统计"买入日涨停封板率"。
- 关键坑: sector_map 的 code 多于 data_cache(行业映射范围更大), hot_codes 构建需 `if c in S` 过滤, 否则 KeyError('301520')。

## 核心结论(区间2024-06-03~2026-07-15, N=3, 10万)
- **可成交性已验证(最大价值)**: 4场景买入日涨停封板率**全部0.0%**(低吸/分歧日, 真能成交); 同框架动量基准仍**54~58%封板**(追强势=追涨停, 又踩买不进/追高站岗); 此前追当日涨幅最强龙头95%封板(虚假)。
- **收益(MA60开门 持3天主口径)**: 动量基准(同框架) **-37.1%**(专挑mom5最强=近期涨停最多, 半数为涨停, 简单持有不退出遇回调站岗); A炸板 **-59.3%**(首阴常不止跌); B回踩 **-33.3%**(弱势接飞刀); **C尾盘偷袭板 +17.1%**(唯一正收益, 持2天更优 +20.3%/回撤7.2%); D断板 **-8.1%**(仅6笔, 样本不足, 断板后常走A字顶)。
- **口径诚实**: "动量基准"是简化同框架版(非生产动量)。生产动量(harness.py原框架, 含套牢盘过滤+自适应止盈止损)主口径 **+32.4%/胜率52.1%/夏普1.31/回撤12.4%**(引自 c_momentum_ma60 回测), 是更可信实盘基准——4场景仅C接近它。
- **结论**: 4场景在"可成交性"完胜追涨类, 但样本内仅C真正赚钱。A/B/D的"日线级简单低吸"α不足, 弱势段易接飞刀; C靠"尾盘转强"的隔天动量赚钱, 回撤最小。

## 逻辑核对要点(已写报告)
① 日线近似分时行为(尾盘拉起/炸板/企稳用OHLC+量能近似, 非分钟级); ② 动量基准≠生产动量(同框架对比仅供参考); ③ 样本含2025下半年弱势段, 低吸类结论有周期依赖(强牛市二波可能不同); ④ 持有期:C/D赌隔天持2天更合理(已测C持2更优), A/B等二波理论上需持5天+本报告仅测2/3天可能低估B; ⑤ 封板率0%的代价="买非封板弱势分歧"本身α较弱。

## 下一步建议(未执行)

# 2026-07-16(续) C 增强版: 接生产退出机制 + 用户4点优化

## 任务(用户4点)
(1) 深耕C: 缩短持有1~2天+隔天高开即走止盈+板块强度/涨停家数过滤; (2) C选股接入生产 ExitRuleEngine(自适应止盈止损)+套牢盘过滤替代简单持有; (3) A/B/D加"大盘多头+板块主升"双过滤重测; (4) 强/弱市分段看C稳健性。

## 框架 harness_c_enhanced.py
- 复用 harness_scenarios 的 build_ctx(新增 atr/rsi14/ma20)/build_sector_lu(板块涨停家数); 复刻 risk/adaptive_exit.get_adaptive_params 到自适应退出(ATR%/RSI/乖离率/市场环境动态调参, 浮盈>5%移动止损护利); 复刻 harness._trapped_ratio(用入场日收盘cp为基准, 非每日自身收盘!) 到 trapped_at。
- 退出模式: hold(简单持有到期)/ gap(持仓第1天T+1开盘≥买入价×1.01即按开盘止盈)/ adp(逐日自适应退出)/ gap_adp(两者叠加)。
- 网格: 退出模式×持有(1/2)×过滤(lu_min=0/2 + trapped≤0.10), 均带 MA60开门闸口; 另 A/B/D 双重过滤(MA60+套牢盘); 强/弱市分段(关闸口, 按全A净值vsMA60+5日动量切 bullish/bearish/normal)。

## 关键坑
① 初版 trapped_at 用"每日自身收盘价"做分母 → 算出来恒≈0.5 > 0.10 → 把所有候选跳过(全0交易)。修正为 harness 口径: cp=入场日收盘, 固定对比历史每日高低(h<=cp全盈利不计, l>=cp全套牢, 否则 v*(h-cp)/(h-l))。② build_sector_lu 初版未过滤 sector_map 中不在 data_cache 的 code → KeyError('000787'); 加 `if c in S`。

## 核心结论(区间2024-06-03~2026-07-15, N=3, 10万, MA60开门)
- **C 增强网格最佳**: 最高收益版 `gap_h2_lu0_trapFalse` = **+24.3%/夏普1.631/回撤7.55%/胜率75.9%**; 增强过滤版 `gap_h2_lu2_trapTrue`(叠加板块涨停≥2+套牢盘过滤) = **+11.4%/夏普1.151/回撤4.53%/胜率75.0%**(收益降、回撤砍近半, 是控风险版)。
- **反直觉(重要)**: 把生产自适应退出引擎(adp)接进 C 反而变差(adp_h2_lu0=-2.0%, adp_h2_lu2=-2.5%); 让 C 赚钱的是"隔天高开即走"(gap, +24.3%)而非生产自适应退出。原因: 生产 ExitRuleEngine 为中期动量+长持设计, 对C的2天短持是负贡献(宽止损让亏损跑)。**用户(2)"接生产退出提夏普"在C上不成立——生产退出机制对短持反噬; 真正有效的是"隔天高开止盈"这种为C量身定的快进快出。**
- **板块涨停≥2过滤未提升胜率**(75.9→75.0基本持平), 仅降回撤; 套牢盘过滤同效。即(1)的"过滤提升胜率"在本样本未验证, 过滤是风控而非alpha增强。
- **强/弱市(关闸口纯看C内在)**: 增强版 强市+11.4%/弱市+3.8%(胜100%但仅24信号日小样本)/震荡0交易; 最高收益版 强市+20.8%/弱市+3.8%/震荡+3.4%。**C 在牛/熊/震荡均为正, 熊市不崩——内在稳健性尚可**, 但熊市收益微薄; MA60闸口价值在控回撤而非选时alpha。
- **A/B/D 双重过滤后仍全负**: A炸板-49~-52%, B回踩-14%, D断板-6%。印证(3): 需更强牛市环境或重定义断板反包(次日确认再打板)才有望转正。
- 对比生产动量基准 +32.4%(hold5)——C仍落后, 但已是可成交场景里最接近实盘的。
