## 龙头策略 × 大盘状态分析 + 择时过滤(机会不对就空仓等待) — harness_c_regime.py
用户观察"近期龙头策略全是负收益", 要求结合大盘分析、找最适合用的时机、不对就空仓。
- **确认近期亏损**: hold=3 龙头策略近60交易日"始终在场"=-7.34%(用户直觉属实)。
- **状态分桶(找亏钱环境)**: 按入场日大盘特征切 250 笔——宽度MA20<45% 时均值 -0.12%(转负, 胜率42%); 20日动量<-5% 时均值 -0.38%(转负); 跌破MA60 时胜率45%/均值+1.07%(低于站上MA60的49.7%/+1.61%)。即"市场宽度弱 / 中期下跌 / 动量深负"是龙头亏钱环境。
- **过滤扫描(信号日不对则空仓等待)**: 11个条件扫描。关键反直觉: 之前B方案的"破MA20空仓"(本表"站上MA20")收益仅121.9%/夏普1.84/回撤28.5%——**MA20太短太吵, 对3天持有期是负贡献**。最优是 **站上MA60**: 收益183.7%/夏普2.16(全场最高)/回撤19.4%(全场最低)/空仓29.8%/177笔。组合过滤(加宽度/波动)反而拉低夏普, 不推荐。
- **近期验证**: hold=3 加"站上MA60"后近60日从 -7.34% → +2.09%(躲开亏损); hold=5 过滤后仍 -8.64%(持5天整体弱, 不推荐)。
- **结论/落地规则**: 每个信号日看等权全A(或沪深300/中证全指)是否站上60日均线——站上才买龙头、跌破则本周期不新建仓、现金等待, 老仓自然到期。回撤从30.7%砍到19.4%、夏普微升、保留85%收益、30%时间空仓。理由: 龙头赚"中期向上+板块轮动"的钱, 中期趋势(MA60)一破整体失效, MA20噪声误杀。
- 交付: harness_c_regime.py + c_regime_results.json + c_regime_report.html + build_regime_report.py。

## MA60闸口"判定时点"对比回测 — harness_c_ma60_timing.py
用户问: 开盘前/14:45/持续2·3天 三种时点哪种胜率收益高? 要求回测后把最优情况文字描述出来供逻辑核对。
- **方法**: 仅参数化"闸口判定所依据的信息时点", 龙头选股/买价/持有期(持3天)完全一致。8变体: baseline / open(T-1收盘站上MA60[T-1], 无前视) / close1445_proxy(T收盘站上MA60[T], 即原MA60口径, 等价于"收盘确认收盘买") / close1445_strict(T收盘 vs MA60[T-1], 严格无前视) / persist2·3_open(开盘前版连续N日) / persist2·3_close(14:45版连续N日)。日线无盘中指数, 14:45用T收盘近似(已在报告中标注前视风险)。
- **核心结论(持3天,10万)**: **开盘前(open)版最优**——收益+221.6% / 胜率50.6% / 夏普2.397(全场最高) / 回撤19.5% / 空仓31.0% / 174笔。比始终在场(+216.7%/48.4%/夏普2.10)更高收益更高胜率, 且回撤砍到19.5%。
- **反直觉点**: open(T-1)版 > close1445(当日收盘)版(+183.7%)。原因: 当日确认版多过滤掉"T-1在上方、T当日小跌破"的少数信号日, 而这些日的3日个股持有实际仍赚钱——MA60是慢趋势过滤器, 单日指数小跌不殃及个股3日行情; open版早一周期入场吃到更多。
- **持续N天版**: persist2_open 与本样本 open 结果完全相同(+221.6%, 说明一旦站上都已持续≥2日); persist3_open 更严(要求3日)→ 收益降至+186.5%/171笔。即"持续"在已验证趋势里不加价值, 反而因少入场降收益。
- **持5天整体差**: 各闸口版多在-14%~+35%间, 仅close1445_proxy+35.5%最高, 但绝对水平远低于持3天任何版 → 结论绑定"持3天"。
- **最优落地逻辑(供用户核对)**: 每信号日(每3交易日)开盘前用T-1收盘判定等权全A是否站上MA60[T-1]; 站上→买当日热门行业龙头1/2/3名(14:44选股收盘买, 持至第3日收盘到期); 跌破→本周期不建仓现金等(记空仓等待), 老仓自然到期; 下一信号日(T+3)重判。判定仅用T-1及更早→无前视, 可隔夜定计划。龙头选股仍用T自身数据, 闸口只做"是否动手"总开关。
- **交付**: harness_c_ma60_timing.py + c_ma60_timing_results.json + c_ma60_timing_report.html + c_tradelog_N3_hold3_open.csv(374行=174买+174卖+26空仓等待)。
- **可视化叠加图**: 用户要求把开盘前版净值曲线与始终在场/14:45版叠加, 并标出空仓期落在哪。写 build_equity_chart.py, 自包含SVG(无外网依赖)输出 c_ma60_equity_chart.html: 图一三变体净值曲线(红线标开盘前版26个空仓信号日), 图二大盘vsMA60同批红线对照——可见空仓日基本落在大盘贴近/跌破MA60的弱势段。窗口253交易日。

## ⚠️ 龙头策略"涨停买不进"现实约束分析 — harness_c_limitup.py(颠覆性发现)
用户问: 14:45选股, 回测里很多票是不是涨停状态根本买不进? → 实测确认是**策略层面的系统性流动性和前视陷阱**, 原回测收益虚假。
- **涨停判定(日线近似)**: 板块 30/688开头=双创20%, 其余=主板10%; 封板=当日涨幅≥涨停线-0.1% 且 收盘≈最高(封死); 视为"14:45买不进"(收盘封≈尾盘已封, 是最宽松定义, 实际比例只会更高)。ST(5%)/北交所(30%)未细分, 样本影响极小。
- **量化(持3天, 区间2024-06-03~2026-07-15)**: 选出的Top3龙头**涨停封板率 95.2%(始终在场)/93.9%(MA60开门)**; **首选(第1名)买不进日占 97.6%/96.7%**。即龙头策略"专挑当日涨幅最强"→ 选出的几乎都是涨停封板票。
- **修正回测(挂MA60开门闸口)**: baseline无视涨停 +322.6%(虚假, 买买不进的涨停板); **skip(封板该槽空置) +4.8%(几乎全跳过, 仅11笔成交)**; **next(顺延非封板次强候选) -3.1%(现实能买到的反而是弱势股, α在买不到的封板龙头里)**。无闸口baseline +290.0%(同样虚假)。
- **颠覆性结论**: 此前所有"龙头+MA60最优 +183%~+322%"的前提(收盘价能买进价)不成立——alpha几乎完全建立在"买到涨停板"上, 而涨停板买不到。真实可执行收益趋近于零。
- **逻辑核对要点(已写报告)**: ①涨停判定用收盘封板代理14:45(有分钟级数据可更严苛); ②板块涨停幅度按代码前缀近似; ③next模式假设14:45能识别封板改选次强(日线已是最乐观假设, 仍-3.1%); ④原回测用"当日涨幅"排序本就有前视(当日涨幅收盘才知道), 14:45应基于实时涨幅, 只会加强"买不进"结论。
- **可行方向(需另行回测)**: (a)改选"强但未封板"票(主动避流动性陷阱, 本质新选股逻辑); (b)T+1开盘追入(次日常高开低走); (c)盘前/早盘选股(引入新前视问题); (d)回归多因子动量框架(本身分散选股、流动性陷阱小)。
- **交付**: harness_c_limitup.py + c_limitup_results.json + c_limitup_report.html(含六段: 颠覆结论/量化/修正回测/逻辑核对/逐笔样例/方向) + c_tradelog_N3_hold3_ma60_limitup_next.csv(142行=71买+71卖, 现实能买版) + c_tradelog_N3_hold3_ma60_limitup_skip.csv(191行=169涨停跳过+11买+11卖)。
