## 0. 先回答「涨停股」问题

**根因不是模型偏好涨停，而是推理可交易性缺陷**（已在 #21 修复）：
1. `code` 经 CSV 读写丢前导零（`00657`→`657`），导致与 `picks_tracking.json` 的零填充字符串对不齐 → **去重失效**（旧代码 `isin` 永远不匹配）。
2. `02_generate_scores` 取每只票「最新一行」，本地残缺库下混进陈旧票 → Top-K 误推（如 08-06 CI 推的 `603221` 实为 07-22 旧数据）。
3. 缺 **涨停 / 一字板不可买入** 过滤 → 推出封板票。

**已修复（`02_generate_scores.py` / `03_select_topk.py`）：**
- 新增 `_flag_untradable`：用 ctx kline 的前一日收盘算 `pct=(close-preclose)/preclose`，`pct≥9.5% 且 收在最高价` 判为涨停/一字板 → 剔除（已用真实数据单元验证：`000001` 2024-02-21 封板被正确标记）。
- `code` 全链路统一零填充字符串；`load_held_codes` 归一化 → 去重恢复（实测从「排除 0 只」→「排除 28 只」）。
- 新鲜度过滤：最新交易日落后 asof >7 自然日的票直接丢弃，避免推陈旧票。

**对正常入选股的买卖时点（与价量研究一致，已验证翻正）：**
- **买点**：信号日 **次日盘中回踩支撑位低吸**（`dip_buf=0.02`），**不追高开/追收盘**。
- **卖点**：触及 **前 60 日最高价 ×0.98（压力位）** 卖出；或 **止损 -5%~-8%**；或 **持有上限 10~20 日到期** 强制了结。

## 1. 回测收益率与胜率

### 1.1 组合级（篮子持有，05）—— 推荐看这个
等权买入每日 Top-K，持有 N 日滚动；市场基准 = 全市场等权买入持有。

| 组合 | 总收益 | 年化 | 夏普 | 最大回撤 | 日胜率 | 超额市场 |
|---|---|---|---|---|---|---|
| 基准(等权市场) | **-6.69%** | -13.98% | -0.68 | -15.59% | 50.0% | — |
| Top3 / hold5 | +11.09% | +25.66% | **0.93** | -12.48% | 55.2% | +17.78% |
| Top3 / hold10 | +8.53% | +19.46% | 0.81 | -18.28% | 51.7% | +15.22% |
| Top3 / hold20 | +5.99% | +13.46% | 0.65 | -15.68% | 55.2% | +12.68% |
| **Top5 / hold10** | **+4.38%** | +9.77% | 0.50 | -17.13% | 55.2% | **+11.08%** |
| Top5 / hold20 | +2.32% | +5.11% | 0.33 | -16.32% | 52.6% | +9.02% |
| Top10 / hold10 | +4.37% | +9.74% | 0.51 | -12.93% | 51.7% | +11.06% |
| Top10 / hold20 | +1.92% | +4.21% | 0.29 | -13.93% | 50.9% | +8.61% |

**要点**：2026-H1 弱市下，所有模型组合 **全部正收益**，跑赢等权市场 **+9%~+18%**。最强为 Top3/hold5，但换仓快；**均衡推荐 Top5/hold10 或 Top3/hold10**（正收益、夏普 0.5~0.8、回撤可控）。

### 1.2 按笔（单信号，04）—— 看 alpha 来源
模型 Top10 各买点 × 各卖点的单笔统计：

- 各买点胜率 **40~42%**，均笔 **-0.35% ~ -1.7%**（timing 噪声大）。
- 卖出规则 `hold_10` 最优（均笔 **+0.08%**，胜率 44%）；`pressure`(压力位) 卖点单笔偏弱，但组合层面贡献了主要超额。
- 市场基准（同期全市场随机 20 日）：胜率 **34.1%**、均笔 **-2.30%** → 模型按笔仍 **显著优于随机**（胜率 +8pp、均笔 +2pp）。

**关键结论**：模型的 alpha 来自 **「选股排序」而非「择时」**。单笔下注 timing 不可靠，**必须篮子分散**才能把排序优势转化为正收益（这也解释了为何 1.1 组合为正、1.2 单笔近零）。

## 2. 与 volume-price-scan 对比

| 维度 | LightGBM 模型 | volume-price-scan(规则) |
|---|---|---|
| 同窗口(2026-H1)样本 | **994 笔**（稠密） | 突破 19 / 回踩 3~68 笔（**极少，统计不可靠**） |
| 信号逻辑 | 21 因子 ML 排序，不依赖特定形态 | 突破放量 / 缩量回踩 + 牛熊门禁 |
| 组合表现 | 弱市全正、跑赢市场 +11~18% | 自身前向验证在适宜环境有效，但信号稀疏 |
| 单笔 timing | 噪声大，需篮子 | 形态内择时精确（回踩低吸已验证翻正） |
| 关系 | 互补而非替代 | 互补而非替代 |

**结论**：同窗口 VP 样本太小无法定论优劣。模型胜在「每日一批候选 + 篮子跑赢市场」；VP 胜在「特定形态 + 精确择时」。两者已并入统一选股登记（`tracking_utils`），可并行运转、互不冲突。

## 3. 值不值得实盘跑？

**结论：值得小仓位实盘验证（篮子式，非单笔），但有 4 个前提。**

1. **用篮子**：至少 Top3~Top5 同时持有，吃 selection alpha、平滑 timing noise。不要单笔下注。
2. **#21 可交易性修复必须先上线**：否则会推「不可买（涨停）/ 重复 / 陈旧」票。本轮已修复待提交。
3. **实盘走 CI（完整库）**：本地库 08-04 起仅 28 只在更新，会推陈旧票；CI 从 release 拉全量库 + 腾讯接口补到当日，数据可信。
4. **样本仍单薄**：仅 2026-H1 一个弱市半年。先用 `tools/trade_journal.py` 模拟盘积累 ≥20~30 笔再放量。

**推荐实盘配置**：`Top5 持有 10 日`（总 +4.4% / 超额 +11% / 夏普 0.5 / 回撤 -17%），或激进些 `Top3 持有 10 日`（总 +8.5% / 超额 +15%）。
