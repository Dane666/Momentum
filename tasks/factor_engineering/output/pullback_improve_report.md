# (B) pullback 改进增量回测 —— 低波动确认

## 方法

- 复用 `VS.build_inv`(板块共振+环境门禁+平台过滤) 产出真实信号, 与 07/08 基线口径一致。
- 给 `pullback` 信号加「低波动确认」: 信号当日 vol60 横截面分位 <= 阈值(健康回踩=低波动)。
- `breakout` 信号不加过滤(已是强信号, 61.7% 胜率)。

## 关键结论

- improved(≤0.33): 20d 收益 5.30% (Δ+2.26pp) / 胜率 59.3% (Δ+8.8pp) / n=369 (基线 686)
- improved(≤0.5): 20d 收益 5.04% (Δ+2.00pp) / 胜率 58.9% (Δ+8.3pp) / n=406 (基线 686)
- improved(≤0.67): 20d 收益 4.23% (Δ+1.18pp) / 胜率 55.1% (Δ+4.5pp) / n=488 (基线 686)

## 讨论

- `breakout_only` 为天花板参考(不减少信号数时无法达到, 但说明突破是主要 alpha 来源)。
- 若要求「不减少信号数」, 可采用 **降权** 而非过滤: 组合中给 breakout 更高优先级,
  pullback 仅作低波动确认后补充, 信号总数不变、质量提升。
